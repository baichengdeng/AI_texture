# Texture — AI 图片元数据管理

本地优先的 AI 生成图片管理软件：读取并展示图片内嵌的生成元数据（提示词 / 参数 / 工作流），支持浏览、搜索、收藏标签、参数导出互转和无限画布参考墙。

**完整操作、交互与快捷键见 [操作指南.md](操作指南.md)。该文件是操作说明的唯一教程来源，功能变化时必须同步更新。**

## 外观设定

交付说明只在这里定义一次，改界面时照着它走：

```text
外观：标准（黄 / 中性纸 / 标准切角 / 等高线 / 标准密度 / 完整动效）
主视觉：图库本身——瀑布流格子按真实宽高比排布，编号与张数是真实数据
页面类型：图库与信息栏为控制台，画板为工作区
主题：浅色默认，深色是完整的第二套
```

固定规则（不随产品改）：只有一个强调色，只表示"当前 / 可点 / 要注意"，只做填充；红色只给删除；切掉一个角＝可以按，不可点的容器是直角，圆角一律 0；宽体大写英文配粗体中文；编号日期计数都是真实字段；细线分区，不堆卡片，无投影与装饰性渐变；动效短、硬、机械，系统要求减少动态效果时全部关闭。

字体：界面为 Saira（宽体几何）+ 中文黑体，正文为中文黑体常规字重，数字用等宽数字。项目不打包字体文件，系统缺失 Saira 时自动退回中文黑体，布局不受影响；要完全一致，把 Saira 的 woff2 放进 `web/fonts/` 并在 `web/style.css` 末尾加 `@font-face`。

## 支持的元数据格式

| 来源 | 载体 | 备注 |
|---|---|---|
| **ComfyUI** | PNG tEXt/zTXt：`prompt` + `workflow` | 从节点图提取正/负提示词与采样参数；workflow JSON 可下载拖回画布 |
| **A1111 WebUI** | PNG `parameters`；JPEG/WebP EXIF | 含 Lora hashes 等长尾字段 |
| **NovelAI** | PNG `Title`/`Description`/`Software`/`Source`/`Comment` | V4 系 char_prompts 保留在原始数据 |
| **NovelAI Stealth** | PNG alpha 通道 LSB 隐写 | 压缩 (`stealth_pngcomp`) 与未压缩 (`stealth_pnginfo`) 双变体 |
| 附加 | EasyDiffusion / InvokeAI / Fooocus / SwarmUI / Draw Things | 照搬 SD Prompt Reader 的现成实现 |

> 解析器代码照搬自 [receyuki/stable-diffusion-prompt-reader](https://github.com/receyuki/stable-diffusion-prompt-reader)（**MIT License, Copyright 2023 Rhys Yang**），保留版权声明，特此致谢。

## 快速开始

```bash
pip install -r requirements.txt   # fastapi uvicorn pillow numpy piexif pywebview
```

**日常启动：双击「启动 Texture.bat」**（自动挑选装了依赖的 Python，避免多版本环境选错解释器；
也可执行 `python launcher.py`，或用无控制台入口「启动 Texture.pyw」）。
启动器里选桌面模式 / 浏览器模式 / 指定端口，端口（默认 4 位 `8770`）与监听地址都能直接改，端口被占用会实时标红并支持一键换端口，选择记在 `data/launcher.json`。右下角显示实际使用的解释器，缺依赖会标红提示。

命令行方式：

```bash
python run.py                     # 原生桌面窗口（pywebview / WebView2，无地址栏）
python run.py --web               # 浏览器模式（调试回退，自动开浏览器）
python run.py --debug             # 原生窗口 + WebView2 开发者工具
python run.py --port 9000         # 换端口（前后端同一端口）
python run.py --host 0.0.0.0      # 允许局域网访问（默认仅 127.0.0.1）
```

**端口策略**（统一由 run.py 管理，默认 8770）：启动前自动检测端口占用——是 Texture 旧实例或残留 python 进程会**自动关闭并接管**（控制台打印 `[端口] 已自动关闭旧进程…`）；被其他程序占用则明确提示并退出，不会误杀。重复启动 `python run.py` 永远只会保留最新一个实例。启动器会先提示占用情况，由你决定是否接管或换端口。

启动后点右上角「＋ 文件夹」（原生窗口弹系统文件夹选择器）添加图片目录即可。数据（SQLite、缩略图）都在 `data/` 下，删除即重置。关闭窗口即退出，端口自动释放。

## 功能

**界面（控制台式骨架）**：深色命令栏（品牌 + 视图切换 + 搜索 + 设置 + 信息栏开关）＋ 竖排导航侧栏（全部图片 / 收藏 / ComfyUI / WebUI / 无数据，带真实计数；文件夹树、标签）＋ 右侧常驻信息栏（`I` 收起 / 展开，默认展开即固定）。左右栏宽度可拖动调整并记忆；浅色为默认，设置里切深色。

- **网格图库**：瀑布流 / 等大网格两种布局（`▤/▦` 切换）、缩略图尺寸滑杆、懒加载缩略图、ComfyUI/WebUI/无数据三类角标、收藏星标、标签
- **多选与批量**：Ctrl/Shift 点选、Ctrl+A 全选、底部批量条（收藏 / 加标签 / 移入回收站）
- **文件夹树**：按根目录递归聚合、显示含子目录总数、折叠状态记忆、可直接从树里移除根目录；三角展开时变黄、折叠回灰，选中目录整行黄色高亮
- **元数据面板**：参数表 / 提示词胶囊 / 原始 JSON；灯箱内 ←→ 翻页，滚轮缩放、双击 2×、拖拽平移
- **提示词胶囊**：提示词按逗号切块，点击即搜同款 tag，`Ctrl`/`Shift` 多选为「同时包含」；正负提示词可分别收起
- **TAG 分格**：给每张图写结构化备注（主体名 + 内容），**格数不限、空格子保留**，新增一格不会弄丢前面写好的内容；分格模板只存「有几格 + 每格叫什么」的分格骨架，可「选图…」批量铺到别的图片上、各图内容各写各的；自动保存，并提供 REST 接口供 AI 直接读写
- **重命名**：信息栏顶部名称可直接改，只改文件名不动目录，收藏/标签/画板引用不失效
- **搜索过滤**：关键词同时命中文件名 / 标签 / 正负提示词 / TAG 分格（NFKC 归一化、逗号＝AND）、ComfyUI/WebUI/无数据分类、标签、仅收藏、「显示子文件夹」开关
- **收藏与标签**：SQLite 持久化；文件指纹 = 大小+前64KB 内容哈希，改名/移动不丢
- **导出互转**：A1111 parameters 文本（NovelAI 采样器自动映射）、ComfyUI workflow/prompt JSON
- **原生桌面窗口**：pywebview/WebView2；浏览器原生弹窗已替换为双模式模态框，`--web` 回退保留

### ComfyUI 节点图

ComfyUI 生成的图里带着两段 JSON，本程序把它们还原成一张能看的节点图：

- `workflow`（UI 格式）有节点位置、尺寸、连线与分组 → **按作者当时的排版画**
- `prompt`（API 格式）有具名输入 → **补出每个参数叫什么**（`steps`、`cfg`、`sampler_name`…）
- 只有 API 格式时按最长路径分层，自动排一遍（上游在左、结果在右）

两处能用：

- **信息栏 →「节点图」页签**：按比例画出节点与连线，节点数、连线数是真实计数；图太宽时自动切成缩略图，名字放在悬停提示里。页签只在 ComfyUI 图片上出现。
- **「送入画板」**（页签里的按钮，或图片节点右键「节点图送入画板」）：把整张节点图变成画板节点——每个 ComfyUI 节点是一个带标题和参数的方框，连线变成画板的边，工作流分组变成分组节点，**并把这张图本身作为一个图片节点接在输出节点（SaveImage）后面**。同一张图可以重复送入，节点 id 自动避让，不会串线。

节点框里的参数值是真实数据；画板右键还有「复制节点参数」「选中上游节点」。导出 `.canvas` 时节点图节点写成文本节点（参数逐行保留），导出自包含 HTML 时画成带参数的方框，都不会丢内容。

### 无限画板（Obsidian Canvas 式）

- **节点类型**：图片 / 文本 / Markdown / 链接 / 分组 / ComfyUI 节点；节点 `id` 与图片指纹 `fileId` 分离，**同一张图可重复放上画板**
- **直接编辑**：双击文本改纯文本、双击 Markdown 改源码（失焦重新渲染），右侧介绍栏同时可用
- **分组**：组是背景容器，选中时与普通节点同样有完整选中态；**拖动组会带走中心点在组内的节点**；颜色染的是节点内部底色而非外框
- **底部固定创建栏**：文本、Markdown、组、链接；选中节点后点「组」会按选中范围自动包组
- **文本与 Markdown**：普通文本双击节点内编辑；Markdown 节点支持标题、列表、引用、代码、粗体、斜体、行内代码和链接。选中文本、Markdown、组或链接时，右侧介绍栏可直接查看并实时修改内容
- **分组层级**：组始终作为背景容器渲染在普通节点下方，选中组不会盖住成员；组内节点可直接点击选择
- **颜色与排版**：节点六色标记之外，可分别设置文字颜色、字号、字体、对齐和行距
- **交互**：框选、Shift/Ctrl 加选、成组拖动、双击空白新建文本
- **改大小**：鼠标在边框附近（22px 内）停 **0.5 秒**弹出八向缩放把手，四条边是长条、四个角是小方块，宽高自由调整（`Shift` 锁比例）
- **连线**：节点**四边中点常驻黄色菱形锚点**，看得见就能直接拖到别的节点成连线；可编辑标签、箭头（末端/双向）、6 色
- **走线样式**：曲线 / 90° 直角 / 45° 折角 / 直线，逐条连线可切换，随画板保存
- **缺角状态灯**：节点右下角缺角＝可编辑（黑）／只读（黄），固定后黄角里带黑图钉；点缺角即切换固定，固定会锁住位置与大小
- **视图**：滚轮以指针为中心缩放、空格/中键/Alt 拖动平移、适应全部（`F`）、100%（`0`）、**每个画板的视口记忆**
- **编辑**：Ctrl+C/V/D、Delete、方向键微调（Shift ×10）、层级 `[` `]`、右键菜单、6 色标记（节点与连线共用 Obsidian 色板）
- **素材抽屉**：内容跟随左侧当前文件夹；提供「显示子文件夹」「接受标签筛选」两个开关；可拖图上板，图库右键「加入当前画板」批量放入
- **保存**：改动后 0.9s 防抖自动保存；revision 机制保证「保存期间的新改动不会被误标已保存」；切换画板/离开视图/关窗前强制落盘（`keepalive`）
- **导入导出**：导出**自包含 HTML**（内嵌缩略图，`?full=1` 内嵌原图，带平移缩放）／导出 **Obsidian `.canvas`**（可指定库根目录写相对路径）／**导入 `.canvas`**（绝对路径、库内相对路径、全库唯一文件名三级匹配；匹配不到的图片保留虚线占位，悬空边自动丢弃）

  index.html           三段式骨架（顶栏 / 侧栏 / 视图 + 信息栏）
  style.css            中性灰设计系统（深浅两套变量）
  app.js               图库：文件夹树 / 过滤 / 瀑布流 / 灯箱 / 多选 / 信息栏 / 节点图预览
  board.js             画板：无限画布 / 连线 / 多选 / 视口记忆 / 自动保存 / .canvas / 节点图
  dialogs.js           双模式弹窗与文件夹选择（原生桥 / 浏览器回退）

## 性能

- 冷扫描 207 张（含 66 张 stealth RGBA）0.11s；二次扫描全缓存命中 <0.05s
- 扫库快路径只读 PNG 文本块（不整图解码）；stealth 全像素检测只在打开详情时按需执行
- 元数据缓存只存轻量摘要（最大行 ~650B），workflow 等大 JSON 详情页从文件重读

## 已知限制 / 下一步

- 测试夹具均为程序生成，**真实世界语料**（真实 A1111/ComfyUI/NovelAI V4.5 图）待收集验证
- A1111 负面提示词内含换行 `Steps:` 的极端样例可能解析偏差
- Windows 长路径(>260)与网络盘/OneDrive 目录未做特殊处理
- 图库仍未做真·DOM 虚拟化：几千张以内靠 `content-visibility` + 懒加载够用，上万张建议再加窗口化
- `.canvas` 的 group 节点只做平铺显示（不含 Obsidian 的「节点归属分组」语义）；导入时保留 label 与位置
- 画板视口存在浏览器 `localStorage`（`texture.view.<boardId>`），换机器/清缓存后回到「适应全部」
